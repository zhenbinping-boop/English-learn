# 词兽星球 · 背单词 × 宠物房间闭环

一个单文件、零依赖的初中英语背单词应用（纯前端 HTML，双击即玩）。

## 怎么玩

下载 `词兽星球.html`，用浏览器（推荐 Chrome/Edge）打开即可，无需安装、无需联网。

## 功能

- **📖 学习**：答题赚币闭环——每轮 10 词，看词选义 / 看义选词 / 听音选词（浏览器 TTS 发音）；答对 +1🪙，连击 ×3/×5/×10 追加奖励，学会新词 +5，满分一轮 +10
- **📚 词书**：人教初中 5 册 2320 词（七上~九上），逐词浏览音标/释义/例句/真人发音，可 ⭐ 标记下轮优先学
- **🏠 房间**：桌宠团团养成——喂食 / 摸摸 / 玩球 / 洗澡 / 睡觉 / 签到 / 衣柜换装 / 家具小铺 / 4 套主题皮肤，四维状态（饱食/心情/精力/清洁）随时间衰减
- **🙂 我的**：学习统计与存档管理
- **间隔重复**：答对的词按 [1,1,2,3,5,7] 天排期复习，答错立即回炉；进度自动保存在浏览器本地

另外收录 `pet-game.html`（团团的房间 v3.1——房间养成 + 同款答题闭环，视觉风格不同的另一版本）。

## 技术说明

- 单 HTML 文件，词书数据压缩内嵌（约 470KB），localStorage 持久化，Web Audio 音效
- 词书数据来源：[ECDICT](https://github.com/skywind3000/ECDICT)（MIT）与 [kajweb/dict](https://github.com/kajweb/dict) 人教初中分册，经脚本转换为自定义 JSON（含预生成干扰项）
- 仅供个人学习使用
